- **D-335** · **This user's notes folder, `~/.ap_coder`, stays where it is for good: it says what it is in a
  README.txt and is hidden in File Explorer, once; Settings, Data & backups names all three places and Report a
  problem opens the logs folder. Nothing moves** (D-231, D-247; `paths.label_notes_folder`, `paths.hide_folder`).
  - **Why:** the owner asked why their user folder holds two folders, APCoder (the data) and .ap_coder (the
    launcher's notes and logs), and asked for one. Every version since the first reads `~/.ap_coder/settings.json`,
    the owner's fallback builds c193eb1 and dffd43a too, and its `current` is all that stops an older program folder
    opening newer data at the same schema: moved or removed, an older build opens the newer data unrefused (or an
    empty database when the data is elsewhere), and makes the folder again. The program inside the data folder
    loses its .env at every start.
  - **How:** after `write_marker`, an ordinary laptop start (never the server, a demo, or with AP_USER_SETTINGS
    set) writes README.txt when it is missing (fixed words, no folder named: nothing goes stale or fails on a name),
    then hides the folder alone through a kernel32 handle of its own, its other attributes kept (a hidden file could
    not be written whole). A README already there: never hidden again, so a folder shown again stays shown. No
    failure stops a start ("Update now?" is asked before it). The start that hid it says so in one line, but not a
    new computer's first. Older builds never list the folder or set attributes: c193eb1's and dffd43a's first phase
    and settle say the same in a labelled home as in a plain one.
  - *Not chosen:* the notes and logs moved into APCoder (older builds unrefused, the logs in two places); a copy of
    the record in APCoder (two copies kept in step, a planted one followed); a junction or %LOCALAPPDATA% (the same
    for older builds); a README.md in the data folder (writes into a folder that is backed up, moved and shared);
    labels without hiding (two folders still shown).

# Bug log

One line per bug: `B-NNN · what broke · severity · the test that keeps it fixed`. Not-reproduced suspicions are
`N-NN` lines, left as they are. The full write-ups of B-01 to B-723 (cause, how to reproduce, fix, lesson) are in
git history: `git show 968cf9d:docs/BUGS.md`.

How to add one: the test first (it fails), then the fix, then a line at the end of the last section, numbered after
the last B- line (`grep -o "B-[0-9]*" docs/BUGS.md | tail -1`).

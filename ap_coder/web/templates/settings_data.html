Backups

Each backup is AP Coder as it was at that moment: the database and every invoice file, saved email, attachment and manager's reply it needs. One is made automatically once a day {% if backup_hours %}between {{ backup_hours }}{% elif backup_at %}at {{ backup_at }}{% else %}when AP Coder starts{% endif %} (the newest 14 are kept{% if server_mode %}, then one a week for 8 weeks and one a month for a year; the backups you make yourself, and those made before an update or a restore, are always kept{% endif %}). A file that did not change is stored once for all the backups, so a daily backup copies only what is new{% if backups %} (in all, the backups take {{ backups_size }}){% endif %}. Make one yourself before big changes, e.g. importing a new chart of accounts.

Put AP Coder back as it was at this backup? The database and the invoice files, saved emails and attachments go back to that moment: everything done since (processed invoices, approvals, lessons, GL changes) is replaced, and unsaved edits on review screens are discarded. Files that came in or changed since are not deleted: they are moved to a set-aside folder in backups, and the page says how many. The current state is backed up first, so this can be undone.

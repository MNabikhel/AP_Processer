Backups

A copy of the database is made automatically once a day when AP Coder starts (the newest 14 are kept). Make one yourself before big changes, e.g. importing a new chart of accounts.

A OneDrive, SharePoint-synced or network folder, so a lost or broken computer does not lose the database. Only the backup copies go there; the database itself stays on this computer.
